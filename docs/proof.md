# Balatro can be beaten: a proof by construction

## Claim
**There is a run of Balatro that can be won.** Precisely: on Balatro 1.0.1o-FULL (`Balatro.exe`
SHA-256 `0D75FE164ACCF3312734D4B37AC98788DD15F0B8E4F9BB8B7F90C4E59DE93F47`), unmodded, on a profile
with everything unlocked, Red Deck, White Stake, the run started from seed **`4XNRUA21`** is won by
the sequence of 715 moves recorded for that seed in [`../wins/routes.jsonl`](../wins/routes.jsonl).

## Proof
1. **The game is deterministic given the seed and the moves.** Every random draw in a run comes from
   the game's own pseudorandom streams, seeded from the run's seed. The same seed and the same moves
   give the same run. Every route the project has published replays move for move to the same final
   state, on the untouched game as well as in the training sim.
2. **The route.** Seed `4XNRUA21`, Red Deck, White Stake: 715 moves, from `select_blind`,
   `play 3,4,7,8`, `play 2,3,4,5,6`, `cash_out` … to `play 5,6,8,9`. The final state's hash is
   `782df2df6accd4f6`.
3. **The win is the game's own.** Replayed from the seed, the moves reach `G.GAME.won = true`: the
   Ante 8 Boss Blind is beaten (24 blinds, 8 bosses). The game sets that flag itself; nothing in
   the harness writes it.
4. **It was checked on the untouched game,** with nothing stripped. The route reproduced the same
   moves, the same number of moves and the same final state. Every one of the 1,549 published
   routes passed the same check ([`../wins/README.md`](../wins/README.md)).

So a winning run exists, and Balatro can be beaten. ∎

## Where it came from
`4XNRUA21` is the first published win: model 0.1, training round 329, on a retried seed, in the
v1 run on 2026-11-01. It is the earliest win whose route was saved. The 10 wins before it were
counted but not recorded, since saving every game started after them. The move list was chosen by
the bot from what a player sees (cards face up, the deck as a set, never the draw order or the
game's random state), so it is a fair-play win, not a search over hidden state.

## What it does not show
- That **every** seed can be won. Some may be unwinnable. 1,549 seeds are proven so far, all of
  them Red Deck, White Stake.
- Anything about other decks, stakes or challenges, or about a fresh profile. Which jokers, tags
  and vouchers can appear depends on unlocks, so the same seed plays differently on a new save.
  The ledger below tracks those, one first seed per item, as wins come in.

## Checking it yourself
With the game source extracted from your own copy (see [`REPRODUCE.md`](REPRODUCE.md); no game
code is in this repository):

    grep '"seed": "4XNRUA21"' wins/routes.jsonl > first_win.jsonl
    python3 train/verify_games.py --src <game source> first_win.jsonl --wins-only --full
