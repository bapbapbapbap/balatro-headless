# Run v4 (current)

**What it is.** Two networks of 1.0's size (table and shop, 3.2M parameters in all, each with its own
critic), credit routed per network on the blind clock, a build-strength potential (`phi_build`) as a second
shaping term, offer values on shop actions, a replay curriculum (30% of games start at ante 4, 5 or 6), and
a shop entropy schedule. Reward `blinds`, Red Deck, White Stake, from random weights, no behavior cloning.
